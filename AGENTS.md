# wanderlust

Single-package Next.js 16 App Router project (Tailwind v4 + shadcn/ui). All app code lives in `src/`; entrypoints are `src/app/layout.tsx` and `src/app/page.tsx`.

## Commands

- `npm run dev` — dev server (Turbopack, Turbopack is default in this Next version) at http://localhost:3000
- `npm run lint` — ESLint
- `npx tsc --noEmit` — typecheck; there is **no** `typecheck` npm script, run this manually before finishing a change
- `npm run build` then `npm start` — production build/serve
- No test framework, no CI, no env vars.

## Next.js 16 gotchas (verified in this repo)

- This Next version has breaking changes vs older releases. Read the relevant guide in `node_modules/next/dist/docs/` before writing route/layout code.
- Layout/route props use the new typed convention: `RootLayout` takes `LayoutProps<"/">` (auto-generated types in `.next/types/**` and `.next/dev/types/**`, which tsconfig includes). Don't hand-write `children: React.ReactNode` signatures.
- `next.config.ts` enables `cacheComponents`, `partialPrefetching`, and `reactCompiler`. With the React Compiler active, don't add manual `React.memo`/`useMemo` optimization-style boilerplate; and follow current caching conventions (see docs above) rather than pre-2026 `dynamic`/`cache` habits.

## Tailwind v4 + shadcn (base-nova / Base UI)

- No `tailwind.config` file. Theme tokens are CSS variables in `src/app/globals.css` (`@theme inline` block); edit styling there, not in a JS config.
- Tailwind is wired via a `turbopack.rules` loader in `next.config.ts` (`@tailwindcss/turbopack`), not a PostCSS config — don't add one.
- `src/components/ui/*` are generated by the shadcn CLI (`components.json`, style `base-nova`, aliases `@/components`, `@/lib`, `@/hooks`; `@/*` maps to `src/*` in tsconfig).
- These components use `@base-ui/react` primitives, **not Radix** — prop/classNames conventions differ from the shadcn components seen in older training data; mirror the existing files when adding new ones.
- `components.json` maps `tailwind.css` to `src/app/globals.css`, so theme changes must stay consistent with that file.
- Fonts: `layout.tsx` loads Josefin Sans (body), Playfair Display (`--font-playfair-display`, mapped to the `--font-heading` token in `globals.css`), and Geist Mono (`--font-geist-mono`, mapped to `--font-mono`).
